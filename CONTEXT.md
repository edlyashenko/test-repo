# Словник навчального дашборда

Короткі пояснення назв, які зустрінуться в коді та розмові. Це готовий довідник; переписувати його для другого уроку не потрібно.

## Glossary

- розробник: людина, яка користується локальним дашбордом для перегляду сесій. Облікових записів і ролі адміністратора в цьому навчальному застосунку немає.
- сесія: один основний файл `<sessionId>.jsonl` безпосередньо в теці `projects/<slug>/`. Вкладені транскрипти субагентів і результати інструментів не є окремими сесіями нашого переліку.
- проєкт: група сесій у спільній теці під `projects/`. Її закодоване імʼя не дає змоги однозначно відновити початковий шлях.
- індекс сесій: короткий перелік сесій, за яким можна знайти потрібну. Для першої навчальної фічі використовуємо лише метадані файлів, без читання тексту розмов.
- джерело: інструмент, із якого походять сесії. У цьому скелеті зареєстроване одне джерело, Claude.
