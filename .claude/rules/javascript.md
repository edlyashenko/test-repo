# JavaScript

- Вбудовані модулі імпортуємо з префіксом `node:`: `node:fs`, `node:path`, `node:os`, `node:url`. Без винятків.
- Тільки named exports. `export default` у репо немає.
- Класів немає. Стан живе в замиканні або в plain-обʼєкті: реєстр джерел у `lib/sources.js` це `Map` у замиканні модуля.
- Робота з файлами синхронна: `readFileSync`, `readdirSync`, `lstatSync`. `node:fs/promises` у репо немає, і заради одного виклику його не додаємо.
- Помилка це `throw new Error('текст')`. Кодів помилок і власних класів помилок немає.
- `catch` пишемо без привʼязки до змінної і з дефолтом замість прокидання далі: `try { st = lstatSync(p); } catch { continue; }`.
- `.mjs` для standalone-скриптів у `scripts/`, `.js` для модулів застосунку.
- Код і коментарі в ньому англійською. Виняток `scripts/verify-hook.mjs`: він говорить з агентом, тому його текст український.
