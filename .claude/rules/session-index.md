# Межі першого індексу сесій

Це правило для майбутнього S1 `session-index` у `lib/claude/`. Кореневий `CLAUDE.md` також застосовується. Зараз `lib/claude/index.js` визначає шляхи й реєструє джерело; функції читання сесій у скелеті ще немає.

- Для S1 збирай індекс із метаданих файлів. Вміст JSONL для цього зрізу не читай; заголовки, події та токени належать наступним крокам roadmap.
- Рахуй лише файли сесій безпосередньо в теці проєкту. Вкладені `subagents/` і `tool-results/` до переліку не входять. Рішення D1 записане в `docs/roadmap.md`.
- Для практики використовуй тільки налаштовані фікстури з `.env.fixtures`. Особисті логи не підключай, у джерело сесій застосунок не записує.
- Обмеження читання вмісту стосується S1. Якщо наступний зріз потребує розбору JSONL, спочатку погодь нові межі й онови правило разом із вимогами.

Цей текст задає інструкцію. Відповідність реалізації та межі доступу потрібно перевірити окремо.
