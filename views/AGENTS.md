# Інструкції для HTML у views/

Цей файл доповнює кореневий `AGENTS.md`. Зараз сторінки формує сервер; окремого клієнтського застосунку немає.

- Для нової сторінки використовуй наявну оболонку `layout()` із `views/layout.js`. У першій фічі `session-index` UI-фреймворк не додаємо.
- Текстові значення з даних пропускай через `esc()` перед вставленням у HTML. У `views/layout.js` це вже зроблено для заголовка та повідомлення `empty()`; рядок `body` оболонка вставляє як готовий HTML.
- Збережи Content-Security-Policy в `layout()`. Не послаблюй її для нової сторінки без окремого рішення людини.
- Правила описують вимоги до змін. Реалізацію перевіряють окремо; наявність цього файла не підтверджує безпеку HTML.
