# Правила для HTML у views/

Цей файл доповнює кореневий `CLAUDE.md` у роботі з HTML. Зараз сторінки формує сервер; окремого клієнтського застосунку немає.

- Для нової сторінки використовуй наявну оболонку `layout()` із `views/layout.js`. У зрізі S1 `session-index` UI-фреймворк не додаємо.
- Текстові значення з даних пропускай через `esc()` перед вставленням у HTML. У `views/layout.js` ця функція вже використана для заголовка та повідомлення `empty()`; рядок `body` оболонка вставляє як готовий HTML.
- Збережи Content-Security-Policy в `layout()`. Не послаблюй її для нової сторінки без окремого рішення людини.
- Правила описують вимоги до змін. Їхню реалізацію перевіряють окремо; сама наявність цього файла не підтверджує безпеку HTML.
