# Урок 2: контекст для першого індексу сесій

Перед тобою скелет `agent-ops-dashboard`. Він уже відповідає на `/api/health` і показує порожню сторінку. Шість синтетичних файлів сесій лежать на диску, але індекс із них ще ніхто не збирає. У цьому уроці важливо навчитися точно описувати такий стан і передавати наступній сесії рішення про майбутню роботу.

Для проходження потрібні два власні файли: `docs/practice/02-context.md` і `docs/practice/handoff.md`. Створи теку `docs/practice/`, коли зберігатимеш перший із них. Решта документів уже видана: її можна читати й уточнювати за потреби. Переписувати всю карту архітектури, встановлювати додаткові skills чи реалізовувати індекс зараз не потрібно.

Почни з [шаблону контексту](../../templates/02-context-pack.md). Якщо складно зрозуміти потрібну докладність, відкрий [заповнений навчальний приклад](context-pack.example.md), а потім [приклад передачі роботи](handoff.example.md). Це пояснювальні документи для читання людиною й агентом. Вони не містять результатів твого запуску та не засвідчують проходження вправи.

[Карта рішень](decision-map.md) допоможе відрізнити вже погоджене від того, що ще треба уточнити. У [промптах](prompts.md) є готові запити для перевірки фактів, запису handoff і продовження в новій сесії. Вони працюють як звичайні повідомлення coding-агенту; SDD для цієї вправи необовʼязковий.

Усі десять кроків можна тримати відкритими в [локальному чеклісті](../../context-check.html) або на [публічній сторінці](https://genkovich.github.io/ai-work-check/context-check.html). Відмітки допомагають памʼятати, де ти зупиняєшся. Підтвердженням роботи залишаються твої файли, фактичні перевірки та відповідь нової сесії.

## Що читати в пакеті

Кореневий [CLAUDE.md](../../CLAUDE.md) містить загальні правила. Поруч із HTML є [views/CLAUDE.md](../../views/CLAUDE.md), а для `lib/claude/` є [правило індексу](../../.claude/rules/session-index.md). Їх можна прочитати явно, навіть якщо твій агент використовує інший формат інструкцій. Так ти перевіряєш передачу змісту; автоматичне завантаження цим не підтверджується.

[Карта архітектури](../architecture-map.md), [словник](../../CONTEXT.md), [roadmap](../roadmap.md) і [бриф](../idea-brief.md) залишаються джерелами для звірки. Коли в них і в коді є різниця, запиши обидва твердження та відкрий відповідний файл. Наприклад, коментар у `lib/sources.js` описує бажану незалежність від адаптера, але `server.js` зараз імпортує `claudeHome()` напряму.

Упродовж уроку працюй на фікстурах через `npm run demo`. `npm start` без налаштування вказує на особисту `~/.claude`, тому для вправи його не запускаємо. Сторінку індексу, JSON-маршрут і перевірки S1 додаватимемо в наступних уроках.
