# Політика роботи з даними сесій

Ці правила стосуються навчального `session-index` і всіх змін, які працюють із його джерелом даних.

- Використовуй тільки синтетичні дані з `fixtures/claude-home/`. Навчальний `scripts/demo.mjs` явно задає абсолютний шлях до цієї теки й порт 4180; `.env.fixtures` цей запуск не читає. Особисту `~/.claude` не відкривай й не підключай.
- Перший перелік будуємо лише з метаданих файлів: імʼя, розмір і час зміни. Вміст JSONL для цієї фічі не читаємо.
- До переліку входять основні `.jsonl` файли безпосередньо в теках `projects/<slug>/`. Вкладені `subagents/` і `tool-results/` до списку не включаємо.
- Застосунок не записує в джерело сесій. Підготовчий скрипт вирівнювання дат може змінювати лише навчальні фікстури.
- Нові потреби, що виходять за ці межі, спочатку погоджуємо з людиною й оновлюємо політику разом із вимогами.

Текст задає інструкції для агента. Технічні права доступу та відповідність реалізації потрібно перевірити окремо.
